#### 3.(1)Generate matrix $A(50\times50)$ and vector $b(50\times1)$ by using random number，and solve the linear system $AX=b$ by using **Gaussian partial pivoting elimination algorithm**.

**Solution:**

```matlab
n=50;
A=round(rand(n)*99)+1;  %生成n阶方阵，元素取值范围为1-100
b=round(rand(n,1)*99)+1;  %生成n*1向量，元素取值范围为1-100
X=[n,1];
T=[A,b];
Temp=[n+1,1];   %用作交换两行

for i=1:n
    for j=i+1:n  %选取绝对值最大的为列主元
        if(abs(T(j,i))>abs(T(i,i)))
            max=T(j,i);
            Temp=T(i,i);
            T(i,i)=T(j,i);
            T(j,i)=Temp;
        end
    end
    
    for k=i+1:n  %计算得到上三角矩阵
        m_ik=T(k,i)/T(i,i); %计算系数
        T(k,i+1:n+1)=T(k,i+1:n+1)-(T(i,i+1:n+1).*m_ik);
        T(k,i)=0;
    end
end  

X(n,1)=T(n,n+1)/T(n,n);  %计算x[n,1]
for i=2:n  %计算x[1:n-1,1]
    X(n-i+1,1)=(T(n-i+1,n+1)-T(n-i+2,n-i+2:n)*X(n-i+2:n,1))/T(i,i);
end
```



#### (2) Randomly generate tridiagonal matrix (30 * 30), and use **Jacobi iteration** and **Gauss Seidel iteration** to solve them respectively. The error of the solution in terms of norm is required to be less than 1/1000. 

**Solution:**

**Jacobi iteration:**

```matlab
%创建30阶随机方阵，元素取值1-100
T=round(rand(30)*99)+1;
D=zeros(30);
U=zeros(30);
L=zeros(30);
B=round(rand(30,1)*99)+1; 
    
%将T-U-L变为对角占优矩阵，使得满足迭代条件
for j=1:29
    U(j,j+1)=-T(j,j+1);
    L(j+1,j)=-T(j+1,j);
end
D(1,1)=sum(abs(T(1,1:2)))+10*rand(1);
for i=2:29
    D(i,i)=sum(abs(T(i,i-1:i+1)))+10*rand(1);
end
D(30,30)=sum(abs(T(30,29:30)))+10*rand(1);

T=(D^-1)*(L+U);
e=max(abs(eig(T)));  %检查系数矩阵特征值
    
Xn=zeros(30,1);  %存储当前的迭代结果
Xn_1=ones(30,1);  %存储上一次的迭代结果
while sqrt(sum(abs(Xn-Xn_1).^2))>0.001
    Xn_1=Xn;
    Xn=(D^-1)*(L+U)*Xn_1+(D^-1)*B;
    fprintf('Xn = %f\n',Xn);
end
```

**Guass-Seidel iteration:**

```matlab
%创建30阶随机方阵，元素取值1-100
A=round(rand(30)*99)+1;
D=zeros(30);
U=zeros(30);
L=zeros(30);
B=round(rand(30,1)*99)+1; 
    
%将D-U-L变为对角占优矩阵，使得满足迭代条件
for j=1:29
    U(j,j+1)=-A(j,j+1);
    L(j+1,j)=-A(j+1,j);
end
D(1,1)=sum(abs(A(1,1:2)))+10*rand(1);
for i=2:29
    D(i,i)=sum(abs(A(i,i-1:i+1)))+10*rand(1);
end
D(30,30)=sum(abs(A(30,29:30)))+10*rand(1);

T=((D-L)^(-1))*U;
C=(D-L)^(-1);
        
e=max(abs(eig(T)));  %检查系数矩阵特征值
    
Xn=zeros(30,1);  %存储当前的迭代结果
Xn_1=ones(30,1);  %存储上一次的迭代结果
while sqrt(sum(abs(Xn-Xn_1).^2))>0.001
    Xn_1=Xn;
    for j=1:30
    Xn(j,1)=T(j,:)*Xn+C(j,:)*B;
    end
    fprintf('Xn = %f\n',Xn);
end
```







#### 4. Use appropriate polynomial interpolation to approximate the following ellipse.

#### (2)$\rho(\theta)=2(1-sin\theta)$(心形线).

对心形线用参数方程表示，以参数 $\theta$ 作为自变量，$\rho$ 作为应变量，将得到的点列转换成直角坐标$x、y$，对直角坐标对，再用同样的方式得到相同范围、更细密的自变量点列，即可使用样条插值。以上面一样的方式分段处理。

```matlab

y=rho(theta_1).*sin(theta_1);

xx_1=rho(theta_11).*cos(theta_11);
yy_1=spline(x,y,xx_1);

theta_2=pi/2:pi/36:pi;

plot(xx_1,yy_1,xx_2,yy_2,xx_3,yy_3,xx_4,yy_4,xx_5,yy_5);
```
